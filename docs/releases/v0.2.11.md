# Input Locker v0.2.11

**Date:** 2026-10-12  
**Tag:** `v0.2.11`

## Highlights

- **Modifiers-Only (`Ctrl+Alt+Shift`) & Single-Key Unlock Combos**: Added `CAS` (`Ctrl+Alt+Shift` with no letter required) preset in Settings as well as support for single-key unlock triggers (`A`, `K`, `U`, etc.) and space-separated / concatenated hotkey strings.
- **Password Dialog `Tab` + `Enter` Navigation**: Fixed keyboard focus order (`Tab` from password field focuses **Unlock** first, then **Cancel**), bound `<Return>`, `<KP_Enter>`, and `<space>` on dialog buttons, and prevented periodic topmost checks from stealing focus away from focused buttons.
- **Resolume / PDF-Presenter-Style Software Update Manager**: Unified modal update dialog across Settings, About, and System Tray right-click menu with one-click background download, real-time progress bar, downgrade prevention (`UP TO DATE` comparison badge), and clean release highlights.
- **Install-Time Win+L Policy & Secure Desktop Recovery**: Inno Setup writes `HKLM\...\DisableLockWorkstation = 1` (64-bit view, verified) so Win+L is blocked after sign-in, plus watchdog recovery on Secure Desktop return.
- **Sub-Second Unlock & Emergency Input Recovery**: PnP touchpad re-enable runs asynchronously on unlock, and a new **Recover Mouse / Touchpad** action in the System Tray restores cursor visibility and touchpad devices anytime.
