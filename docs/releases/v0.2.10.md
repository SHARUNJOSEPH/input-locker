# Input Locker v0.2.10

**Date:** 2026-10-09  
**Tag:** `v0.2.10`

## Highlights

Faster lock screen, and **no PowerShell UAC on every launch** after a normal install.

## What's new

- **Install-time touchpad helper** — Setup registers scheduled task `\InputLocker\InputLockerTouchpadHelper` (highest privileges, on demand). The app starts it with `schtasks /Run` — no UAC on normal launches. Uninstall removes the task.
- **Faster lock overlay** — Overlay appears before Precision Touchpad PnP disable. Device cut runs in the background; registry gesture cut stays immediate. Startup warms the touchpad device cache.
- **Portable fallback** — If the scheduled task is missing (source / zip without install), helper start still uses one-shot RunAs (UAC once per session).

## Upgrade notes

- **New install:** Run `InputLocker-Setup-v0.2.10.exe` (admin once for Setup). Later launches should not show a PowerShell UAC dialog.
- **Already installed:** Either reinstall with the new Setup, or run `helpers\deploy_no_uac.ps1` / `register_touchpad_task_once.bat` as Administrator once after updating the exe.

## Manual soak

1. Fresh install of Setup-v0.2.10 → launch from Start Menu → **no** PowerShell UAC.
2. Lock → overlay appears immediately (tens of ms, not seconds).
3. While locked: 3/4-finger trackpad gestures do not open Task View / switch desktops.
4. Unlock (hotkey / password) restores touchpad.
5. Kill app while locked → relaunch → touchpad recovers.
